# Data Engineering Zero to Hero

My journey from SQL beginner to Data Engineer.

This repository documents my learning journey through hands-on practice.
I am starting with SQL Foundations and will add new stages as I actually
learn them.

---

## Current Stage: SQL Foundations

I started my Data Engineering journey with SQL.

The goal of this stage is to understand how data is stored, retrieved,
filtered, combined, changed, and managed inside a database.

---

## What I Have Learned

### 1. Database Setup

I learned how to:

- Create a database
- Create tables
- Insert sample data
- Recreate a database for practice

**Learning Outcome:**

I can create a basic database environment and prepare tables containing
data for SQL practice.

---

### 2. SELECT

I learned how to:

- Select all columns
- Select specific columns
- Retrieve data from different tables

**Learning Outcome:**

I can retrieve the data I need from a database instead of always
selecting everything.

---

### 3. Filtering

I learned:

- `WHERE`
- `=`
- `!=`
- `>`
- `>=`
- `<`
- `<=`
- `AND`
- `OR`
- `NOT`
- `BETWEEN`
- `IN`
- `LIKE`

**Learning Outcome:**

I can filter database records using conditions and retrieve only the rows
that match my requirements.

---

### 4. Sorting

I learned:

- `ORDER BY`
- `ASC`
- `DESC`
- Sorting using multiple columns

**Learning Outcome:**

I can organize query results in ascending or descending order and control
how multiple columns are sorted.

---

### 5. DISTINCT and TOP

I learned:

- `DISTINCT`
- `TOP`
- Finding highest values
- Finding lowest values
- Finding recent records

**Learning Outcome:**

I can remove duplicate values and limit query results to the records I
am interested in.

---

### 6. Aggregations

I learned:

- `SUM()`
- `COUNT()`
- `AVG()`
- `GROUP BY`
- `HAVING`

**Learning Outcome:**

I can summarize data, calculate totals and averages, count records,
group results, and filter grouped results.

---

### 7. JOINs

I learned:

- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL JOIN
- LEFT ANTI JOIN
- RIGHT ANTI JOIN
- FULL ANTI JOIN
- CROSS JOIN
- Multiple-table JOINs

**Learning Outcome:**

I can combine related data from multiple tables and understand which
records are included or excluded by different types of JOINs.

---

### 8. DDL

I learned:

- `CREATE TABLE`
- `ALTER TABLE`
- `ADD`
- `DROP COLUMN`
- `DROP TABLE`

**Learning Outcome:**

I can create and modify the structure of database tables.

---

### 9. DML

I learned:

- `INSERT`
- `INSERT ... SELECT`
- `UPDATE`
- Updating multiple columns
- Updating `NULL` values
- `DELETE`
- `TRUNCATE`

**Learning Outcome:**

I can add, modify, and remove data from database tables.
