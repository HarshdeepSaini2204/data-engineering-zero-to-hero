## 🧠 What I Learned

I learned the important rules for Set Operators:

1. `ORDER BY` can be used only once.
2. Queries must have the same number of columns.
3. Matching data types are required.
4. Columns must be in the same order.
5. The first query controls the aliases.
6. The correct columns must be mapped.

I also practiced using `UNION` to combine results from different tables.
