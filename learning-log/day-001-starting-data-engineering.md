## 🧠 What I Learned

Today I learned that Git and GitHub are different:

- **Git** tracks changes to my project on my computer.
- **GitHub** stores and shares my Git repository online.

I also learned the basic workflow:

```text
Create files
     ↓
git init
     ↓
git add .
     ↓
git commit
     ↓
Connect to GitHub
     ↓
git push
```
